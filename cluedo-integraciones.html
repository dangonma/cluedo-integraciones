Expediente · El caso

Elige vuestro misterio

Hay cuatro incidencias abiertas. Elegid una y leed bien el aviso: ahí empiezan las pistas.

Paso 1 · El flujo

Para resolver el misterio, elegid el flujo correcto

Tarea en equipo

Ponedlo en común y dibujadlo en una pizarra o cartulina. El flujo tiene 3 cajitas: elegid las que creáis oportunas para vuestra integración, dejad espacio entre ellas y unidlas con flechas para indicar la dirección.

Dos preguntas que ayudan: ¿el documento sale de SAP o entra en SAP? ¿Es un proceso estándar (legal, igual para todas las empresas) o uno a medida (hecho para nosotros)?

¿Ya lo tenéis dibujado? Pulsad el flujo que habéis elegido para comprobarlo.

Paso 2 · Los componentes

Ubicad los sospechosos en el flujo

Tarea en equipo

Colocad en vuestro dibujo los componentes que creáis necesarios: dentro de cada cajita o encima de las flechas. Tomaos el tiempo que haga falta. Podéis volver a las cartas cuando queráis.
